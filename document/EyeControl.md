# EyeControl

Sistema em Python para Windows que rastreia a atenção visual/inclinação da cabeça do usuário via webcam e reposiciona automaticamente janelas sobrepostas (como *scrcpy*, Picture-in-Picture ou players de mídia) entre múltiplos monitores, aplicando deslocamento periférico (*offset*).
